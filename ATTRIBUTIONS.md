# Open-source references and asset attribution

This project uses original application code and artwork unless a file says otherwise.

Design and engineering references:

- Lil'DressUp by RodFireProductions — WTFPL-2.0 code. Its permanent/changeable layers, linked front/back hair, equal-size canvases and PNG composition informed the v5 wardrobe architecture. https://github.com/RodFireProductions/Lil-DressUp
- paperbuddy by JLChnToZ — MIT. Its nested selector and layer-tree concepts informed wardrobe configuration. https://github.com/JLChnToZ/paperbuddy
- Dollmaker NEO by lottev1991 — MIT code and CC BY-SA 4.0 default images. Its mobile fullscreen, touch input and export flows informed interaction design. https://github.com/lottev1991/Dollmaker-NEO
- DecoratingGame by Ashley Rice — MIT code; artwork excluded from the MIT grant. Its mouse/touch placement flow informed the room editor. https://github.com/ashleysally00/DecoratingGame
- blueprint3d by furnishup — open-source interior model/view architecture reference. https://github.com/furnishup/blueprint3d

No third-party artwork is copied into the project unless the exact asset, creator, source URL and license are added below before release.
